# vibescoder-syndicate

Mirror of `vibescoder.dev/syndicate.xml` for RSS-based importers (Substack) that reject feeds served directly from the blog.

## How it works

1. A GitHub Action (`sync-substack.yml`) runs every 30 minutes
2. It fetches the live feed from `vibescoder.dev/syndicate.xml`
3. Compares GUIDs against the mirror to detect new posts
4. If new posts are found:
   - Updates `syndicate.xml` (preserving existing GUID busts)
   - Generates `single-import.xml` with a unique GUID for Substack import
   - Posts a summary with the import URL

## Files

| File | Purpose |
|------|---------|
| `syndicate.xml` | Full mirror of the curated syndication feed (all `syndicate: true` posts) |
| `single-import.xml` | Single-post feed for Substack import — avoids per-feed-URL dedup |

## Importing to Substack

After the Action runs and detects a new post:

1. Go to **Substack Dashboard → Settings → Import posts**
2. Paste: `https://raw.githubusercontent.com/carryologist/vibescoder-syndicate/main/single-import.xml`
3. Confirm the import

## Why single-import.xml?

Substack's importer dedupes against its internal history per feed URL. Adding a new post to an existing feed and re-importing silently skips it. Using a separate file with a timestamped GUID bypasses this cache.

## Manual trigger

```bash
gh workflow run sync-substack.yml --repo carryologist/vibescoder-syndicate
```

## Canonical source

The canonical feed lives at [vibescoder.dev/syndicate.xml](https://vibescoder.dev/syndicate.xml), generated by the Next.js engine in `carryologist/the-vibe-coder`. Only posts with `syndicate: true` in their frontmatter are included.
